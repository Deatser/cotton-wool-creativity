# cotton wool creativity — сайт ватных ёлочных игрушек

Перенос магазина с конструктора sites.google.com на собственный хостинг.
Блок 1: витрина-копия текущего сайта. Блоки 2-3 (контакты, документы, согласия,
вход в админку через Firebase, форма заказа) добавляются поверх этой основы.

## Что где лежит

```
build.py            сборщик: из data/toys.json + photos/ делает готовый сайт в site/
data/toys.json      каталог: 59 игрушек, названия, размеры, цены, разделы, список фото
templates/          шаблоны страниц (Jinja2)
static/css/         стили
static/js/          скрипты витрины: меню, тёмная шапка, просмотр фото
static/fonts/       Lato и Oswald, лежат у нас, а не тянутся с серверов Google
photos/             оригиналы фотографий (папка «ДЛЯ САЙТА» как прислана)
photos/с-сайта/     обложки каталога, которых не нашлось в присланной папке
site/               ГОТОВЫЙ САЙТ. Это то, что заливается на хостинг
```

`site/` целиком собирается заново, руками там ничего править не нужно.

## Как собрать

```
py -m pip install pillow jinja2
py build.py
```

Сборка кладёт результат в `site/`. Картинки, которые уже посчитаны, не пересчитываются:
чтобы пережать всё заново, удалите `site/img`.

## Как посмотреть локально

```
cd site
py -m http.server 8000
```

и открыть http://127.0.0.1:8000

## Как добавить или изменить игрушку

Пока админки нет (это блок 3), каталог правится в `data/toys.json`:

- `name`, `size`, `note` — подпись под фото в каталоге;
- `price` — число или `null`. Если `null`, цена и кнопка «купить» не показываются,
  игрушка считается проданной или сделанной под заказ;
- `section` — `in_stock`, `repeat` или `custom`;
- `folder` — папка внутри `photos/`, откуда берутся фотографии;
- `photos` — имена файлов по порядку, первый показывается на странице первым;
- `cover` + `cover_folder` — файл обложки для каталога;
- `slug` — адрес страницы, `/igrushki/<slug>/`.

После правки — `py build.py`.

## Что нужно поменять перед публикацией

В `build.py` строка `BASE_URL` — сейчас там временный адрес. Подставить настоящий домен,
от него считаются `canonical` и `sitemap.xml`.

## Размеры картинок

- обложка каталога: квадрат 600 и 300 px;
- фото на странице игрушки: 900 px, при увеличении 1600 px;
- всё в JPEG, качество 82, прогрессивный.

Оригиналы в `photos/` на хостинг не заливаются, они нужны только для сборки.
